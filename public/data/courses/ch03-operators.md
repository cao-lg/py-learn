## 一、算术运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `+` | 加法 | `10 + 5` → 15 |
| `-` | 减法 | `10 - 5` → 5 |
| `*` | 乘法 | `10 * 5` → 50 |
| `/` | 除法 | `10 / 5` → 2.0 |
| `//` | 整除 | `10 // 3` → 3 |
| `%` | 取模 | `10 % 3` → 1 |
| `**` | 幂运算 | `2 ** 10` → 1024 |

```python
a, b = 10, 3
print(a + b)   # 13
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

---

## 二、比较运算符

返回布尔值 `True` 或 `False`：

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `==` | 等于 | `5 == 5` → True |
| `!=` | 不等于 | `5 != 3` → True |
| `<` | 小于 | `5 < 10` → True |
| `>` | 大于 | `5 > 10` → False |
| `<=` | 小于等于 | `5 <= 5` → True |
| `>=` | 大于等于 | `5 >= 10` → False |

**链式比较（Python 特色）：**
```python
x = 5
print(1 < x < 10)   # True（等价于 1 < x and x < 10）
print(0 < x > -1)   # True
```

## 三、逻辑运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `and` | 逻辑与 | `True and False` → False |
| `or` | 逻辑或 | `True or False` → True |
| `not` | 逻辑非 | `not True` → False |

**优先级：** `not` > `and` > `or`

```python
print(True or False and False)   # True
print((True or False) and False) # False
```

**短路求值：**
```python
x = 0
print(x > 0 and 10 / x > 1)  # False（and 短路）
print(x == 0 or 10 / x > 1)  # True（or 短路）
```

## 四、赋值运算符

```python
x = 10
x += 5    # x = x + 5 → 15
x *= 2    # x = x * 2 → 30
x /= 3    # x = x / 3 → 10.0
```

---

## 五、运算符优先级

| 优先级 | 运算符 |
|--------|--------|
| 1 | `()` 括号 |
| 2 | `**` 幂运算 |
| 3 | `* / // %` 乘除 |
| 4 | `+ -` 加减 |
| 5 | `< <= > >=` 比较 |
| 6 | `== !=` 等于判断 |
| 7 | `= += -=` 赋值 |

```python
print(2 + 3 * 4)      # 14（先乘后加）
print((2 + 3) * 4)    # 20（先算括号）
```
