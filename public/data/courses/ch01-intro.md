## 一、什么是 Python？

Python 是一种**简洁、优雅、易学**的编程语言，由 Guido van Rossum 于 1991 年创建。

**核心特点：**
- 🧠 **语法简洁** - 代码接近自然语言
- 🌍 **应用广泛** - Web开发、数据分析、人工智能等
- 📦 **生态丰富** - 拥有海量第三方库

## 二、第一个程序：Hello World

### 基础输出

```python
print("Hello, World!")
```

**运行结果：**
```
Hello, World!
```

### 代码解析

| 元素 | 说明 |
|------|------|
| `print()` | Python内置输出函数 |
| `"..."` | 字符串（用引号包裹的文本） |
| `\n` | 换行符 |

### 多种输出方式

```python
# 1. 字符串输出（单引号或双引号）
print('Hello')
print("World")

# 2. 多行输出（三引号）
print("""第一行
第二行
第三行""")

# 3. 数字输出（不需要引号）
print(42)

# 4. 表达式计算输出
print(2 + 3)  # 输出 5
```

## 三、基本数学运算

Python 支持所有基本数学运算：

```python
# 基础运算
print(10 + 5)   # 加法 → 15
print(10 - 5)   # 减法 → 5
print(10 * 5)   # 乘法 → 50
print(10 / 5)   # 除法 → 2.0（结果是浮点数）
print(10 // 5)  # 整除 → 2
print(10 % 3)   # 取余 → 1
print(2 ** 10)  # 幂运算 → 1024
```

### 运算优先级

遵循数学运算规则：**先括号，再乘除，后加减**

```python
print((2 + 3) * 4)   # 先算括号内 → 20
print(2 + 3 * 4)     # 先乘后加 → 14
```
